# Railway Reservation API Specification

This document describes the REST endpoints currently exposed by the Spring Boot controllers.

- **Base URL:** `http://localhost:8080`
- **Content type for JSON requests:** `application/json`
- **Date format:** ISO 8601 calendar date, `YYYY-MM-DD`
- **Authentication:** None is currently configured.

## Common value formats

`gender` accepts `MALE`, `FEMALE`, `OTHER`, or `PREFER_NOT_TO_SAY`.

Reservation `status` is one of `CONFIRMED`, `WAITLISTED`, or `CANCELLED`. A confirmed reservation has a `seatNumber`; a waitlisted or cancelled reservation has `seatNumber: null`.

## Trains

### Create a train

`POST /api/trains`

**Parameters:** None.

**Request body:** All fields are required. `totalSeats` must be positive; `fare` must be greater than zero and have at most two decimal places. Source and destination must differ.

```json
{
  "trainNumber": "12901",
  "trainName": "Deccan Express",
  "source": "Mumbai",
  "destination": "Pune",
  "totalSeats": 2,
  "fare": 185.00
}
```

**Success response:** `201 Created`

```json
{
  "trainNumber": "12901",
  "trainName": "Deccan Express",
  "source": "Mumbai",
  "destination": "Pune",
  "totalSeats": 2,
  "fare": 185.00
}
```

**Other responses:** `400 Bad Request` for invalid fields or identical source and destination; `409 Conflict` if the train number already exists.

### List trains

`GET /api/trains`

**Parameters:** None.

**Success response:** `200 OK`, an array of train objects.

```json
[
  {
    "trainNumber": "12901",
    "trainName": "Deccan Express",
    "source": "Mumbai",
    "destination": "Pune",
    "totalSeats": 2,
    "fare": 185.00
  }
]
```

### Search trains by route

`GET /api/trains/search`

**Query parameters:**

| Name | Required | Description |
| --- | --- | --- |
| `source` | Yes | Route origin; must not be blank. |
| `destination` | Yes | Route destination; must not be blank. |

Example: `GET /api/trains/search?source=Mumbai&destination=Pune`

**Success response:** `200 OK`, an array of matching train objects. A route with no matches returns an empty array.

```json
[
  {
    "trainNumber": "12901",
    "trainName": "Deccan Express",
    "source": "Mumbai",
    "destination": "Pune",
    "totalSeats": 2,
    "fare": 185.00
  }
]
```

### Find a train by number

`GET /api/trains/{trainNumber}`

**Path parameters:** `trainNumber` — train number to look up.

Example: `GET /api/trains/12901`

**Success response:** `200 OK`

```json
{
  "trainNumber": "12901",
  "trainName": "Deccan Express",
  "source": "Mumbai",
  "destination": "Pune",
  "totalSeats": 2,
  "fare": 185.00
}
```

**Other response:** `404 Not Found` if the train number does not exist.

## Passengers

### Create a passenger

`POST /api/passengers`

**Parameters:** None.

**Request body:** All fields are required. `age` must be from 0 through 120.

```json
{
  "name": "Asha Kumar",
  "age": 20,
  "gender": "FEMALE"
}
```

**Success response:** `201 Created`. `passengerId` is generated by the database.

```json
{
  "passengerId": 1,
  "name": "Asha Kumar",
  "age": 20,
  "gender": "FEMALE"
}
```

**Other response:** `400 Bad Request` for a blank name, missing field, invalid age, or unsupported gender.

### List passengers

`GET /api/passengers`

**Parameters:** None.

**Success response:** `200 OK`, an array of passenger objects.

```json
[
  {
    "passengerId": 1,
    "name": "Asha Kumar",
    "age": 20,
    "gender": "FEMALE"
  }
]
```

### Find a passenger by ID

`GET /api/passengers/{passengerId}`

**Path parameters:** `passengerId` — database-generated passenger ID.

Example: `GET /api/passengers/1`

**Success response:** `200 OK`

```json
{
  "passengerId": 1,
  "name": "Asha Kumar",
  "age": 20,
  "gender": "FEMALE"
}
```

**Other response:** `404 Not Found` if the passenger does not exist.

## Reservations

### Create a reservation

`POST /api/reservations`

**Parameters:** None.

**Request body:** All fields are required. `passengerId` must be positive. `journeyDate` must be today or a future date. The source and destination must match the selected train's route (case-insensitive).

```json
{
  "trainNumber": "12901",
  "passengerId": 1,
  "source": "Mumbai",
  "destination": "Pune",
  "journeyDate": "2026-10-01"
}
```

**Success response:** `201 Created`. If a seat is free, status is `CONFIRMED`; otherwise it is `WAITLISTED` and `seatNumber` is `null`.

```json
{
  "reservationId": 1,
  "trainNumber": "12901",
  "passengerId": 1,
  "journeyDate": "2026-10-01",
  "source": "Mumbai",
  "destination": "Pune",
  "fare": 185.00,
  "status": "CONFIRMED",
  "seatNumber": 1
}
```

**Other responses:** `400 Bad Request` for invalid fields or a route that does not match the train; `404 Not Found` if the train or passenger does not exist.

### Find a reservation

`GET /api/reservations/{reservationId}`

**Path parameters:** `reservationId` — database-generated reservation ID.

Example: `GET /api/reservations/1`

**Success response:** `200 OK`, a reservation object in the same format as the create-reservation response.

```json
{
  "reservationId": 1,
  "trainNumber": "12901",
  "passengerId": 1,
  "journeyDate": "2026-10-01",
  "source": "Mumbai",
  "destination": "Pune",
  "fare": 185.00,
  "status": "CONFIRMED",
  "seatNumber": 1
}
```

**Other response:** `404 Not Found` if the reservation does not exist.

### Cancel a reservation

`POST /api/reservations/{reservationId}/cancel`

**Path parameters:** `reservationId` — reservation to cancel.

**Request body:** None.

**Success response:** `200 OK`. `promotedReservation` is the first waiting reservation promoted into the released seat, or `null` if no one was waiting.

```json
{
  "cancelledReservation": {
    "reservationId": 1,
    "trainNumber": "12901",
    "passengerId": 1,
    "journeyDate": "2026-10-01",
    "source": "Mumbai",
    "destination": "Pune",
    "fare": 185.00,
    "status": "CANCELLED",
    "seatNumber": null
  },
  "promotedReservation": {
    "reservationId": 2,
    "trainNumber": "12901",
    "passengerId": 2,
    "journeyDate": "2026-10-01",
    "source": "Mumbai",
    "destination": "Pune",
    "fare": 185.00,
    "status": "CONFIRMED",
    "seatNumber": 1
  }
}
```

If no reservation is promoted, the response ends with:

```json
{
  "cancelledReservation": {
    "reservationId": 1,
    "trainNumber": "12901",
    "passengerId": 1,
    "journeyDate": "2026-10-01",
    "source": "Mumbai",
    "destination": "Pune",
    "fare": 185.00,
    "status": "CANCELLED",
    "seatNumber": null
  },
  "promotedReservation": null
}
```

**Other responses:** `404 Not Found` if the reservation does not exist; `409 Conflict` if it is already cancelled.

### Check seat availability

`GET /api/reservations/availability`

**Query parameters:**

| Name | Required | Description |
| --- | --- | --- |
| `trainNumber` | Yes | Train to check; must not be blank. |
| `journeyDate` | Yes | Journey date in `YYYY-MM-DD` format. |

Example: `GET /api/reservations/availability?trainNumber=12901&journeyDate=2026-10-01`

**Success response:** `200 OK`

```json
{
  "trainNumber": "12901",
  "journeyDate": "2026-10-01",
  "totalSeats": 2,
  "availableSeatCount": 1,
  "availableSeatNumbers": [2]
}
```

**Other response:** `404 Not Found` if the train does not exist.

### List confirmed passengers for a train journey

`GET /api/reservations/confirmed`

**Query parameters:**

| Name | Required | Description |
| --- | --- | --- |
| `trainNumber` | Yes | Train to query; must not be blank. |
| `journeyDate` | Yes | Journey date in `YYYY-MM-DD` format. |

Example: `GET /api/reservations/confirmed?trainNumber=12901&journeyDate=2026-10-01`

**Success response:** `200 OK`, an array ordered by seat number. No confirmed bookings returns an empty array.

```json
[
  {
    "reservationId": 1,
    "passengerId": 1,
    "passengerName": "Asha Kumar",
    "age": 20,
    "gender": "FEMALE",
    "source": "Mumbai",
    "destination": "Pune",
    "journeyDate": "2026-10-01",
    "seatNumber": 1
  }
]
```

**Other response:** `404 Not Found` if the train does not exist.

### List reservations for a passenger

`GET /api/reservations/by-passenger/{passengerId}`

**Path parameters:** `passengerId` — passenger whose reservations should be listed.

Example: `GET /api/reservations/by-passenger/1`

**Success response:** `200 OK`, an array of reservation objects in the same format as the create-reservation response, ordered by journey date descending. A passenger with no reservations receives an empty array.

```json
[
  {
    "reservationId": 1,
    "trainNumber": "12901",
    "passengerId": 1,
    "journeyDate": "2026-10-01",
    "source": "Mumbai",
    "destination": "Pune",
    "fare": 185.00,
    "status": "CONFIRMED",
    "seatNumber": 1
  }
]
```

**Other response:** `404 Not Found` if the passenger does not exist.

## Error responses

Errors use Spring Boot's default error response; the project does not currently define a custom error DTO. Common status codes include:

- `400 Bad Request` — request validation failed, a date is malformed, or a reservation route does not match its train.
- `404 Not Found` — a referenced train, passenger, or reservation does not exist.
- `409 Conflict` — duplicate train number or attempt to cancel an already-cancelled reservation.

Example default error shape (exact fields can vary by Spring Boot configuration):

```json
{
  "timestamp": "2026-09-28T12:00:00.000+00:00",
  "status": 404,
  "error": "Not Found",
  "path": "/api/trains/99999"
}
```
